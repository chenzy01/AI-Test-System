# 测试报告模板

测试报告六大板块模板与完整示例。输出前对照本文件检查板块完整性。

## 一、六大板块模板

```markdown
# 测试报告

## 1. 测试概述
- 测试目的：<本次测试的目标>
- 被测系统：<系统/模块名 + 版本号>
- 测试周期：<起止日期>
- 测试人员：<角色/姓名>
- 测试环境：<环境地址/配置>

## 2. 测试范围
- 范围内：<覆盖的模块/需求，可列 RA 编号>
- 范围外：<明确不测的内容>
- 覆盖说明：<需求覆盖率>

## 3. 执行统计
| 指标 | 值 |
|------|-----|
| 用例总数 | 100 |
| 已执行 / 执行率 | 95 / 95% |
| 通过 / 通过率 | 90 / 94.7% |
| 失败 / 阻塞 / 未执行 | 3 / 2 / 5 |

## 4. 缺陷分析
- 缺陷总数 / 密度
- 按严重度分布、按模块分布、按状态分布
- 遗留缺陷清单

## 5. 风险评估
- 遗留风险列表（风险描述 + 影响程度）

## 6. 结论建议
- 测试结论：通过/有条件通过/不通过
- 发布建议
- 后续行动（责任方 + 动作 + 期限）
```

## 二、执行统计示例

| 指标 | 值 |
|------|-----|
| 用例总数 | 120 |
| 已执行数 / 执行率 | 118 / 98.3% |
| 通过数 / 通过率 | 112 / 94.9% |
| 失败数 | 4 |
| 阻塞数 | 2 |
| 未执行数 | 2 |

## 三、缺陷分析示例

| 严重度 | 数量 | 占比 |
|--------|------|------|
| 致命 | 1 | 5% |
| 严重 | 4 | 20% |
| 一般 | 8 | 40% |
| 轻微 | 7 | 35% |
| 合计 | 20 | 100% |

## 四、风险评估示例

| 风险 | 影响 | 建议 |
|------|------|------|
| 缺陷 BUG-005（支付超时未回滚）未修复 | 可能导致用户资金纠纷 | 发布前必须修复 |
| 兼容性仅覆盖 Chrome，未测 Safari | iOS 用户可能异常 | 补一轮 Safari 回归 |
