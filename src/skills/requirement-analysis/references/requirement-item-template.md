# 需求条目模板与填写规范

本文件定义需求清单（RA）的九字段填写规范与输出模板。输出前必须对照本文件逐字段检查。

## 一、字段填写规范

| # | 字段 | 必填 | 填写要求 | 反例（不合格） |
|---|------|------|---------|---------------|
| 1 | 需求ID | 是 | RA-<三位序号>，从 RA-001 连续编号，全局唯一 | 跳号、复用已删编号 |
| 2 | 需求类型 | 是 | 仅限 8 类枚举，判定见 requirement-type-classification.md | 自造「体验需求」等新枚举 |
| 3 | 需求描述 | 是 | 一句话说明「做什么」，主语+动作+对象 | 「订单相关功能」这类空泛描述 |
| 4 | 需求原文/来源 | 是 | 逐字引用原文，或标注文档名+章节/行号 | 无出处、凭记忆改写 |
| 5 | 业务规则 | 否 | 校验/计算/状态流转等规则，逐条列出；无则填「—」并登记疑点 | 写「按常规处理」 |
| 6 | 约束条件 | 否 | 数据/时间/环境等约束；无则「—」并登记疑点 | 漏掉明确的数值上限 |
| 7 | 验收标准 | 是 | 可观测、可验证的结果，精确到字段/状态/数值 | 「功能正常」「符合预期」 |
| 8 | 优先级 | 是 | P0/P1/P2，定义见 SKILL.md 输出约定 | 凭感觉定级 |
| 9 | 疑点与假设 | 否 | 关联 Q-xxx / A-xxx，无则「—」 | 把疑点直接写成结论 |

## 二、完整示例

| 字段 | 示例值 |
|------|--------|
| 需求ID | RA-003 |
| 需求类型 | 业务规则 |
| 需求描述 | 用户下单时系统按「应付金额 = 单价 × 数量 - 优惠金额」计算订单金额 |
| 需求原文/来源 | 《订单模块需求》第 2.3 节：「下单时应付金额 = 单价 × 数量 - 优惠金额」 |
| 业务规则 | 1) 优惠金额不得大于订单金额的 50%；2) 计算结果保留两位小数，四舍五入 |
| 约束条件 | 单价、数量、优惠金额均为正数 |
| 验收标准 | 下单后订单表 order 的 payable_amount 字段 = 单价 × 数量 - 优惠金额，精确到 0.01 |
| 优先级 | P0 |
| 疑点与假设 | Q-002（优惠金额上限 50% 未明确来源） |
