# 测试设计方法选择指南

测试点提取中「建议测试方法」的选型决策树与各方法展开步骤。方法选型禁止硬套：RA 不满足适用条件时注明「不适用」。

## 一、选型决策树

按顺序判断，命中即选（一个 RA 可匹配多个方法）：

1. 含「输入/输出可分类的字段」（如性别、支付方式、状态枚举）→ **等价类划分**。
2. 含「范围型字段」（数值/长度/时间/数量，有上下限）→ **边界值分析**。
3. 含「多条件组合决定行为」（如优惠资格需同时满足金额+会员等级）→ **决策表**。
4. 含「状态/生命周期」（如订单 pending→paid→shipped→completed）→ **状态迁移**。
5. 含「端到端业务流」（如注册→登录→下单→支付→收货）→ **场景法**。
6. 历史缺陷密集 / 高风险点（金额计算、并发扣款等）→ **错误推测**。

## 二、各方法展开步骤

### 等价类划分
- 列出输入域，划分有效等价类与无效等价类。
- 无效类必须覆盖四种子类：不传 / 类型错 / 超界 / 格式错。
- 每个等价类取一个代表值 → 对应 ≥1 个 TP。

### 边界值分析
- 对每个边界应用 7 类取值：最小 / 最小-1 / 最小+1 / 最大 / 最大-1 / 最大+1 / 精度边界。
- 临界值必须取「边界 ± 最小步长」；金额类补两位小数精度边界。

### 决策表
- 列出全部条件桩与动作桩，展开全部条件组合。
- 组合数超限时按「成对组合」裁剪，注明裁剪依据与遗漏风险。
- 业务互斥组合标注「不可达」；每个规则列对应 ≥1 个 TP。

### 状态迁移
- 以状态迁移表列出全部边（合法 + 非法）。
- 每条边对应 ≥1 个 TP；非法边必须定义期望表现（拒绝 + 状态不变 + 具体错误码）。

### 场景法
- 基本流 1 条 + 备选流 N 条 + 异常流 M 条，逐条对应 TP。
- 写明整条路径步骤序列与终点状态。

### 错误推测
- 逐条写出推测依据（历史缺陷模式，如「并发扣款超卖」）。
- 无依据的推测不采纳。

## 三、方法选型示例

| RA | 特征 | 选型 |
|----|------|------|
| 用户注册（手机号必填） | 手机号可分类 + 11 位长度上限 | 等价类划分 + 边界值分析 |
| 优惠资格判定 | 金额 + 会员等级 两条件组合 | 决策表 |
| 订单生命周期 | 多状态流转 | 状态迁移 |
| 下单全流程 | 端到端业务流 | 场景法 |
| 并发扣减库存 | 高风险点 | 错误推测 |
