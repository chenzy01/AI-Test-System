# 覆盖度规则与去重合并规则

测试点提取中「测试类型」「覆盖度指标」「去重合并」的标准定义。步骤 4 去重、步骤 5 覆盖度自检时使用。

## 一、测试类型 6 类定义（全链路统一枚举）

| 类型 | 定义 | 典型测试点 |
|------|------|-----------|
| 功能 | 验证系统按需求正常完成功能 | 下单成功、登录成功 |
| 边界 | 验证输入/状态在边界值处的行为 | 数量=0/1/10/11、金额精度边界 |
| 异常 | 验证非法输入、依赖失败、并发冲突等异常场景 | 输入非法类型、重复提交、超时中断 |
| 性能 | 验证响应时间/并发量/容量等指标 | P95 响应 ≤ 500ms、100 并发 |
| 兼容 | 验证不同环境/终端/浏览器的适配 | iOS/Android、Chrome/Safari |
| 安全 | 验证权限/鉴权/加密/审计 | 越权访问、敏感字段脱敏 |

## 二、覆盖度指标

| 指标 | 标准 |
|------|------|
| 需求点覆盖率 | 100%（无孤儿 RA）|
| 类型覆盖 | 每个 RA ≥ 功能/边界/异常 三类（无对应维度备注理由）|
| 边界值覆盖 | 每个范围字段 ≥ 1 组 最小/最小-1/最小+1/最大/最大-1/最大+1 |
| 决策表覆盖 | 条件组合全覆盖或注明裁剪依据 |
| 状态迁移覆盖 | 全部边覆盖（含非法边）|

## 三、去重合并规则

两个 TP 判定为等价（应合并）当且仅当同时满足：
1. 同输入等价类；
2. 同断言目标；
3. 同后置状态。

合并后重新连续编号，在推导附录标注合并来源。反之，一个 TP 含多个独立验证目标（如同时断言提示文案与数据回滚）→ 拆分为多个 TP。

## 四、覆盖矩阵格式

```
| RA-ID | 功能 | 边界 | 异常 | 性能 | 兼容 | 安全 |
|-------|------|------|------|------|------|------|
| RA-001 | TP-001 | TP-002,TP-003 | TP-004 | — | — | — |
```

单元格填该组合的 TP 编号列表；无覆盖填「—」并备注理由（如「该需求无兼容性要求」）。
