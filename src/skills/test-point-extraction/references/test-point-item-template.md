# 测试点条目模板与填写规范

本文件定义测试点清单（TP）的六字段填写规范与输出模板。输出前必须对照本文件逐字段检查。

## 一、字段填写规范

| # | 字段 | 必填 | 填写要求 | 反例（不合格） |
|---|------|------|---------|---------------|
| 1 | 测试点ID | 是 | TP-<三位序号>，从 TP-001 连续编号，全局唯一 | 跳号、复用已删编号 |
| 2 | 关联RA-ID | 是 | 回链 ≥1 个 RA 编号，多值用「、」分隔 | 引用不存在的 RA 编号 |
| 3 | 测试关注点 | 是 | 一句话验证目标，含「输入/前置 → 期望」方向 | 「测试下单功能」这类无断言方向的描述 |
| 4 | 测试类型 | 是 | 仅限 功能/边界/异常/性能/兼容/安全 | 自造「体验测试」等新枚举 |
| 5 | 建议测试方法 | 是 | 等价类/边界值/决策表/状态迁移/场景法/错误推测，可多值用「+」连接 | 声明方法但无对应推导过程 |
| 6 | 优先级 | 是 | P0/P1/P2，定义见 SKILL.md 输出约定 | 凭感觉定级 |

## 二、完整示例

| 字段 | 示例值 |
|------|--------|
| 测试点ID | TP-012 |
| 关联RA-ID | RA-003 |
| 测试关注点 | 验证优惠金额 = 订单金额的 50% 时下单成功且应付金额正确 |
| 测试类型 | 边界 |
| 建议测试方法 | 边界值分析 |
| 优先级 | P0 |

## 三、边界值取值规范（有输入的功能点必须覆盖）

| 边界点 | 取值 |
|--------|------|
| 最小值 | 最小值、最小-1、最小+1 |
| 最大值 | 最大值、最大-1、最大+1 |
| 空值/类型 | 空、null、非法类型 |
| 精度 | 精度边界（如金额两位小数） |

## 四、测试点清单输出模板

```markdown
## 测试点清单

| 测试点ID | 关联RA-ID | 测试关注点 | 测试类型 | 建议测试方法 | 优先级 |
|---------|-----------|-----------|---------|-------------|--------|
| TP-001 | RA-001 | ... | 功能 | 等价类划分 | P0 |
```
