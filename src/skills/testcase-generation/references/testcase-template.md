# 用例模板

用例全表输出模板与完整示例。输出前对照本文件检查字段完整性。

## 一、用例全表模板

```markdown
## 用例全表

| 编号 | 名称 | 需求溯源 | 优先级 | 前置条件 | 测试数据 | 测试步骤 | 预期结果 |
|------|------|---------|--------|---------|---------|---------|---------|
| TC-ORDER-001 | 验证提交订单时优惠金额合法，系统计算应付金额正确 | RA-003 / TP-012 | P0 | 已登录用户；购物车有 1 件商品 | 商品单价 100.00 元；数量 2；优惠券 20.00 元 | 1. 进入订单页<br>2. 输入优惠券码 COUPON20<br>3. 点击「提交订单」 | 1. 订单页加载成功<br>2. 优惠券校验通过，显示优惠 20.00 元<br>3. 订单创建成功，应付金额 = 100×2-20 = 180.00 元 |
```

## 二、完整示例（含全部八字段）

| 字段 | 值 |
|------|-----|
| 编号 | TC-ORDER-002 |
| 名称 | 验证提交订单时优惠金额超过订单金额 50%，系统拒绝下单 |
| 需求溯源 | RA-003（业务规则：优惠上限 50%）/ TP-013（异常） |
| 优先级 | P0 |
| 前置条件 | 已登录用户；购物车有 1 件商品，金额 100.00 元 |
| 测试数据 | 优惠券码 COUPON60（优惠 60.00 元，超过订单金额 50%） |
| 测试步骤 | 1. 进入订单页<br>2. 输入优惠券码 COUPON60<br>3. 点击「提交订单」 |
| 预期结果 | 1. 订单页加载成功<br>2. 提示「优惠金额不得超过订单金额的 50%」<br>3. 订单未创建，订单表 order 无新增记录 |

## 三、步骤/预期配对检查要点

1. 预期条数 = 步骤条数，编号一一对应。
2. 每步预期精确断言：字段名 + 具体值/状态/错误码。
3. 步骤中不夹带预期（「系统扣减余额」写在预期，不写在步骤）。
