# 用例评审标准库（references/review-criteria）

> 渐进式披露文件：SKILL.md 阶段 2/3/4 引用本文件。

## 1. 五维检查清单

### 1.1 覆盖度（权重 30%）

- [ ] C1.1 每个 REQ 都有 ≥1 个 TP 且 ≥1 个 TC（无孤儿 REQ/TP）
- [ ] C1.2 每个 REQ 覆盖 {功能, 边界, 异常} 三类测试类型
- [ ] C1.3 每个范围型字段存在 ±最小步长 的边界用例（如金额 5000.01/4999.99）
- [ ] C1.4 每个输入字段覆盖四类无效输入：不传/类型错/超界/格式错
- [ ] C1.5 状态类需求覆盖全部迁移边（含非法边）
- [ ] C1.6 判定表类需求覆盖全部条件组合或裁剪有书面依据
- [ ] C1.7 每个 TC 回链 ≥1 个 TP（无孤儿 TC）
- [ ] C1.8 无明显重复用例（同输入+同断言出现两次）

### 1.2 可执行性（权重 30%）

- [ ] C2.1 每个步骤含 动词+对象+具体数据值
- [ ] C2.2 每条测试数据有具体值与构造方式（无"任意值/合法值"）
- [ ] C2.3 每条预期可精确断言（具体字段+值/状态/错误码，命中禁词清单即不合格）
- [ ] C2.4 接口步骤含 方法+URL+请求体；数据断言含具体 SQL
- [ ] C2.5 等待/轮询步骤含具体时长或轮询条件
- [ ] C2.6 前置条件写"状态"而非"动作"，且可构造

### 1.3 逻辑性（权重 20%）

- [ ] C3.1 预期条数 = 步骤条数，编号一一对应
- [ ] C3.2 步骤不夹带预期（系统自动行为写在预期列）
- [ ] C3.3 步骤顺序符合真实操作顺序（如先登录后操作、先造数后验证）
- [ ] C3.4 前置条件充分且必要（不缺关键状态、不堆无关状态）
- [ ] C3.5 用例独立，无「执行 TC-xxx 后」类隐式依赖
- [ ] C3.6 测试数据与步骤中的引用值一致（步骤写 11，数据列写 12 即不合格）

### 1.4 异常流覆盖（权重 15%）

- [ ] C4.1 八类异常逐类核对：输入非法/依赖失败/重复提交/并发冲突/权限不足/资源耗尽/超时中断/数据异常
- [ ] C4.2 错误场景同时断言：错误码或文案 + 数据不变项
- [ ] C4.3 非法状态迁移边有对应用例且期望表现明确（拒绝+状态不变+错误码）
- [ ] C4.4 补偿/回滚类场景有断言（如库存回补 +1）

### 1.5 规范性（权重 5%）

- [ ] C5.1 TC 编号连续不跳号，回链编号有效
- [ ] C5.2 用例标题符合「验证XX时YY」格式
- [ ] C5.3 优先级按定级规则映射（P0 主流程/资金、P1 边界与关键异常、P2 其他）
- [ ] C5.4 模块划分按业务域，单任务内模块名唯一
- [ ] C5.5 表格字段完整、格式统一

## 2. 问题分级规则

| 级别 | 定义 | 典型问题 | 处理要求 |
|------|------|---------|---------|
| A（阻断） | 用例不可用或结论不可信 | 步骤夹带预期；断言模糊（命中禁词）；隐式依赖；孤儿 REQ/TP；步骤缺数据值无法执行；预期与步骤错位 | 必须修订并复审 |
| B（重要） | 用例可用但质量受损 | 数据不可构造；缺数据不变断言；优先级错定；边界取值错误；非法状态边缺失；步骤冗余/缺步 | 限期修订 |
| C（建议） | 不影响执行的质量瑕疵 | 命名不规范；格式不统一；可读性差；模块名不统一 | 统一修订规则即可 |

## 3. 评分模型

- **扣分规则**：A 级 −20 分/条，B 级 −10 分/条，C 级 −3 分/条；各维度得分 = max(0, 100 − 该维度问题扣分合计)。
- **总分** = Σ(维度得分 × 权重)。
- **等级划分**：优秀 ≥90；良好 80~89；合格 70~79；不合格 <70。
- **降级规则**：缺上游材料时，覆盖度与异常流覆盖维度按 60 分计（不及格线），并在报告中声明「评分受限」；总分按实际权重折算。

## 4. 常见缺陷模式库（评审速查）

| 模式 | 判定特征 | 定级 |
|------|---------|------|
| 步骤夹带预期 | 步骤中出现"系统将/应/会"+结果描述 | A |
| 断言模糊 | 预期命中禁词（"校验通过""提示合理"等） | A |
| 隐式依赖 | 前置条件出现"执行 TC-xxx 后""沿用上一条用例数据" | A |
| 数据泛指 | 数据列出现"任意值/合法值/若干" | B |
| 缺数据不变断言 | 错误场景只断言错误码，未断言相关数据不变 | B |
| 优先级错定 | 边界/资金类用例定为 P2，或提示文案类定为 P0 | B |
| 边界取值错误 | 临界值取"边界附近"而非 ±步长（5000.1 而非 5000.01） | B |
| 覆盖空洞 | 孤儿 REQ/TP；某 REQ 缺异常类用例；非法状态边无用例 | A |
| 前置条件写动作 | 前置条件写"登录系统"而非"账号 XX 已登录" | C |
| 命名/格式违规 | 标题不符「验证XX时YY」；编号跳号 | C |
