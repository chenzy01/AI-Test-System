# 测试设计方法库（references/design-methods）

> 渐进式披露文件：SKILL.md 阶段 2/3 引用本文件。每个方法含：定义、适用信号、标准步骤、产出物格式、示例、常见陷阱。

## 0. 方法选型表

| 需求特征 | 首选方法 | 硬性要求 |
|---------|---------|---------|
| 输入可分类 | 等价类划分 | 无效类四子类全覆盖 |
| 范围型字段（数值/长度/时间/数量） | 边界值分析 | 临界取 ±最小步长 |
| 多条件组合决定行为 | 判定表 | 全组合或注明裁剪 |
| 状态/生命周期 | 状态迁移 | 非法边全覆盖 |
| 端到端流程 | 场景法 | 基本+备选+异常流 |
| 多因素两两交互 | 成对组合 | 高风险组合强制补充 |
| 历史缺陷密集/高风险点 | 错误推测 | 依据可查 |

## 1. 等价类划分

- **定义**：将输入域划分为若干等价类，同一类中任一值触发相同处理逻辑，取代表值即可代表整类。
- **适用信号**：需求含输入字段，且字段取值可按业务规则分群。
- **标准步骤**：
  1. 列出该 REQ 的全部输入字段与输出字段；
  2. 对每个输入字段划分有效等价类（按业务规则）与无效等价类；
  3. 无效等价类必须逐一检查 4 个子类：**不传**（null/缺省）、**类型错**（字符串传数值等）、**超界**（超出取值域）、**格式错**（不符合正则/精度）；
  4. 每个等价类取 1 个代表值（优先取边界内典型值）；
  5. 每类生成 1 个 CTP，断言=该类预期处理 + 字段级结果 + 数据状态不变项。
- **产出物**：等价类表

  | 字段 | 等价类 | 类别（有效/无效-子类） | 代表值 | 产出 CTP |
  |------|--------|----------------------|--------|---------|

- **示例**：订单数量字段，规则「1~10 件」：有效类 {1..10} 代表值 5；无效类：不传（null）、类型错（"abc"）、超界（11）、格式错（1.5）。
- **陷阱**：无效类只断言"提示错误"不合格，必须断言具体错误码/文案且相关数据不变。

## 2. 边界值分析

- **定义**：缺陷聚集于边界，对输入/输出边界取边界值、边界±最小步长、超界值。
- **适用信号**：范围型字段（数值/长度/时间/数量/日期区间）。
- **标准步骤**：
  1. 找出全部边界（上限、下限、长度上限、时间窗起止）；
  2. 确定最小步长（金额 0.01、数量 1、长度 1 字符、时间 1s；需求未定义时按 1 并在备注声明假设）；
  3. 对每个边界取 7 类值：最小值、最大值、临界（边界±步长）、空值、非法类型、超界值、精度边界；
  4. 每值生成 1 个 CTP，断言含边界两侧的接受/拒绝与数据状态；
  5. 边界来自 CL 默认值时，备注标注「依赖 CL-xxx 确认」。
- **产出物**：边界值表

  | 字段 | 边界 | 步长 | 取值集合 | 各值产出 CTP |
  |------|------|------|---------|-------------|

- **示例**：金额上限 5000（CL 默认）：取值 5000.00、4999.99、5000.01、0.00、0.01、-1、500000。
- **陷阱**：「临界值」必须量化到 ±步长，禁止"边界附近"；上限与下限都要取临界。

## 3. 判定表

- **定义**：多个条件组合决定多个动作时，用表穷举条件组合与对应动作。
- **适用信号**：需求出现 ≥2 个条件共同决定行为（如 库存×在售×数量合法 共同决定是否创建订单）。
- **标准步骤**：
  1. 提取条件桩（互斥且可独立判定的条件；取值超过 3 个的先做等价类归并）与动作桩；
  2. 列出全部条件组合（2^n 或乘积）；
  3. 组合数 ≤16 全展开；17~64 用成对组合裁剪并补充高风险组合；>64 必须与用户确认裁剪策略（见 `coverage-rules.md` 第 3 节）；
  4. 每个规则列生成 1 个 CTP；业务上互斥的组合标注「不可达」并说明原因；
  5. 每个动作在表中至少出现 1 次。
- **产出物**：判定表（条件桩行 × 组合列 → 动作桩行），每列标注 CTP 编号或「不可达」。
- **示例**：创建订单 = f(库存充足?, 商品在售?, 数量合法?) → 动作：创建订单/拒绝+错误码 30001/30002/30003。
- **陷阱**：条件取值必须互斥穷尽；裁剪后必须补测高风险组合并披露。

## 4. 成对组合（Pairwise）

- **定义**：多因素多水平时保证任意两因素任意两水平至少出现一次的受控裁剪。
- **适用信号**：因素 ≥3 且全组合 >64，或交互风险集中在两两因素之间。
- **标准步骤**：
  1. 列出因素与全部水平；
  2. 生成成对覆盖组合集（工具生成或手工构造）；
  3. 每个组合生成 1 个 CTP；
  4. 从全组合中挑出高风险组合（全边界组合、全极端值组合、历史缺陷映射组合）强制补充；
  5. 输出裁剪说明（原组合数/裁剪后数/裁剪依据/遗漏风险）。
- **产出物**：因素水平表 + 成对组合表 + 强制补充组合清单。
- **示例**：浏览器(3) × 分辨率(3) × 登录态(2)，全组合 18，成对覆盖 9 组 + 强制补充 2 组高风险。
- **陷阱**：成对覆盖不能替代全组合，仅用于受控裁剪且必须披露。

## 5. 状态迁移

- **定义**：以状态机视角覆盖全部合法/非法迁移边。
- **适用信号**：需求含状态字段与明确/隐含的状态流转。
- **标准步骤**：
  1. 列出全部状态（含初始态、终态、异常态）；
  2. 列出全部触发事件；
  3. 建状态迁移表：起始态 × 事件 → 目标态，逐边标注合法/非法；
  4. 非法迁移必须定义期望表现（拒绝 + 状态不变 + 具体错误码）；需求未定义 → 登记 CL；
  5. 每条边生成 1 个 CTP；
  6. 状态有时效（超时自动流转）时，补充定时迁移边。
- **产出物**：状态迁移表

  | 起始态 | 触发事件 | 目标态 | 合法/非法 | 期望表现 | 产出 CTP |
  |--------|---------|--------|----------|---------|---------|

- **示例**：订单状态 待支付/支付中/已支付/已取消/退款中/已退款，全边覆盖（含「已支付→待支付」非法边）。
- **陷阱**：只测主路径漏非法边；非法边期望不能写"不可操作"，必须有具体断言。

## 6. 场景法

- **定义**：以用户视角按业务流路径设计场景：基本流 + 备选流 + 异常流。
- **适用信号**：端到端流程（下单→支付→发货→收货）、多步骤业务。
- **标准步骤**：
  1. 画基本流（happy path 完整步骤序列）；
  2. 识别每个步骤的分支：备选流（合法但非主流）、异常流（失败/中断/取消）；
  3. 每条流生成 1 个 CTP，写明整条路径的步骤序列、每步输入与终点状态；
  4. 标注备选流插入点（在基本流第几步处分支）。
- **产出物**：场景清单

  | 流类型 | 路径步骤序列 | 分支插入点 | 终点状态 | 产出 CTP |
  |--------|-------------|-----------|---------|---------|

- **示例**：基本流 选品→下单→余额支付→支付成功→发货通知；备选流 余额不足转银行卡支付；异常流 支付中断→订单挂起→恢复/取消。
- **陷阱**：场景步骤不落具体数据（金额、商品、账号）即不可执行。

## 7. 错误推测

- **定义**：基于历史缺陷模式与经验，针对高风险点补充测试点。
- **适用信号**：历史缺陷密集模块、新上线高风险逻辑、支付/扣减/权限类功能。
- **标准步骤**：
  1. 列出推测依据（见本文件附录缺陷模式清单）；
  2. 逐条写明「缺陷模式 → 本需求的映射点」；
  3. 生成 CTP，断言精确到字段与值；
  4. 无依据的推测不采纳。
- **产出物**：推测依据表

  | 缺陷模式 | 映射点 | 推测说明 | 产出 CTP |
  |---------|--------|---------|---------|

- **示例**：模式「金额计算精度丢失」→ 映射：折扣价 49.9×0.85 的舍入规则 → CTP 断言结果字段精确值。
- **陷阱**：推测必须有来源，禁止"我觉得可能出问题"式泛化。

## 附录：历史缺陷模式清单

| 编号 | 缺陷模式 | 映射提示 |
|------|---------|---------|
| D01 | 金额计算精度丢失 | 乘法/除法/折扣/汇率计算，断言精确到分并验证舍入规则 |
| D02 | 并发超卖/超扣 | 库存/余额/名额扣减，断言最终数值与流水条数一致 |
| D03 | 幂等失效 | 重复提交/重试，断言仅生效一次且第二次返回幂等错误码 |
| D04 | 空值/边界未判空 | null/空串/0 的区分处理，断言不崩溃且错误码明确 |
| D05 | 编码乱码 | 生僻字/emoji/多语言输入，断言存储与展示一致 |
| D06 | 分页越界 | 页码超界/页大小 0，断言返回约定错误码 |
| D07 | 越权访问 | 水平越权（访问他人数据）/垂直越权（低权限调高权限接口） |
| D08 | 缓存不一致 | 更新后读旧值，断言读写一致性与缓存失效时机 |
| D09 | 浮点比较 | 金额用浮点 == 比较导致判断错误，断言临界金额判断正确 |
| D10 | 时区/时间边界 | 跨天/夏令时/月末，断言时间字段与时区转换正确 |
