# 覆盖度与裁剪规则（references/coverage-rules）

> 渐进式披露文件：SKILL.md 阶段 4/5 引用本文件。

## 1. 覆盖度指标（硬性，不达标禁止输出）

| 指标 | 计算方式 | 达标线 |
|------|---------|--------|
| 需求点覆盖率 | 已覆盖 REQ 数 / 全部 REQ 数 | = 100% |
| 类型覆盖 | 每个 REQ 拥有的测试类型集合 | ≥ {功能, 边界, 异常} 三类；某类确实不适用时在覆盖矩阵备注理由 |
| 边界覆盖 | 每个范围型字段的 ±步长 临界 TP 组数 | ≥ 1 组（上限与下限各一组） |
| 无效类覆盖 | 每个输入字段的无效等价类子类 | 不传/类型错/超界/格式错 四类全覆盖 |
| 组合覆盖 | 判定表被覆盖的规则列 / 全部规则列 | = 100%，或裁剪有书面依据 |
| 迁移覆盖 | 已覆盖状态迁移边 / 全部边 | = 100%（含非法边） |

## 2. 去重与合并规则

- **等价判定标准**（同时满足才可合并）：同 REQ + 同输入等价类 + 同断言目标 + 同后置状态。
- **合并方式**：保留 1 个 TP，「设计方法」列合并（如「等价类划分+边界值分析」）；合并后全部 TP 重新连续编号，并在推导附录标注合并来源（如「TP-007 由 等价类 CTP-3 与 边界值 CTP-9 合并」）。
- **不合并的情形**：断言目标不同（如一个断言提示文案、一个断言数据回滚）→ 按独立性拆分为多个 TP；输入相同但后置状态不同 → 不合并。

## 3. 组合裁剪规则（判定表/多因素场景）

- 组合数 ≤16：全展开，禁止裁剪。
- 组合数 17~64：成对组合 + 高风险组合强制补充，输出裁剪说明表。
- 组合数 >64：必须向用户确认裁剪策略，禁止自行决定。

**高风险组合定义**（裁剪时必须全部保留）：

1. 全边界组合（所有条件同时取边界值）；
2. 全空值组合（所有条件同时为空/不传）；
3. 历史缺陷映射组合（见 design-methods 附录 D01–D10 的映射点）；
4. 互斥条件被同时触发的组合。

**裁剪说明表**（输出至报告「裁剪说明与风险提示」章节）：

| 场景 | 原组合数 | 裁剪后组合数 | 裁剪方法 | 裁剪依据 | 遗漏风险 |
|------|---------|-------------|---------|---------|---------|

## 4. 覆盖矩阵输出格式

| REQ | 功能 | 边界 | 异常 | 状态流转 | 权限 | 并发 | 备注 |
|-----|------|------|------|---------|------|------|------|

单元格填写 TP 编号列表；无 TP 的单元格填「—」，并在备注列写明理由（如「该 REQ 无状态维度」）。
